# Gestion de Contacts

Application web Full Stack permettant de gérer une liste de contacts à travers une interface simple et intuitive.

## Fonctionnalités

- **Ajouter** un nouveau contact.
- **Afficher** la liste des contacts.
- **Modifier** les informations d’un contact.
- **Supprimer** un contact.

Chaque contact contient les informations suivantes :
- Nom complet
- Numéro de téléphone
- Adresse e-mail

## Technologies utilisées

- **Frontend :** React.js, JavaScript, CSS
- **Backend :** Node.js, Express.js
- **Base de données :** MongoDB, Mongoose
- **API :** REST API

## Objectif du projet

Ce projet a pour objectif de mettre en pratique les concepts du développement Full Stack JavaScript, notamment la création d’une interface utilisateur, le développement d’une API REST et la gestion des données dans une base de données MongoDB.
